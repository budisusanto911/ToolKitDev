5. Panduan Pengerasan APK (Hardening) & Remediasi Kode

Rekomendasi konfigurasi dan snippet kode untuk menutup celah keamanan secara permanen:

A. Nonaktifkan Cleartext Traffic (res/xml/network_security_config.xml)

<network-security-config> <base-config cleartextTrafficPermitted="false"> <trust-anchors> <certificates src="system" /> </trust-anchors> </base-config> </network-security-config>

B. Enkripsi Kredensial via EncryptedSharedPreferences (Kotlin)

val masterKey = MasterKey.Builder(context) .setKeyScheme(MasterKey.KeyScheme.AES256_GCM) .build() val securePrefs = EncryptedSharedPreferences.create( context, "secure_vault", masterKey, EncryptedSharedPreferences.PrefKeyEncryptionScheme.AES256_SIV, EncryptedSharedPreferences.PrefValueEncryptionScheme.AES256_GCM )

C. Proteksi Anti-Frida & HMAC Signature (C++ NDK & Server-Side)

1. Terapkan HMAC-SHA256 Request Signing dengan dynamic timestamp dan nonce untuk menggagalkan modifikasi payload pada proxy atau hook.
2. Deteksi Frida port 27042 dan pemindaian /proc/self/maps pada level native C++ library.
3. Kunci seluruh exported Activity sensitif dengan permission berlevel signature.
